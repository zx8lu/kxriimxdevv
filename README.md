# kxriimxdevv

Personal portfolio & freelance services platform for **Labaci Abdelkarim (@zx8lu)** — Full-Stack Engineer, FiveM Lua Architect and Windows systems optimization specialist.

## Highlights

- Single-file static website (`index.html`) — no build step, no dependencies to install.
- 16 specialized services, 5 packages and 9 case studies with images and pricing.
- Multi-step checkout with order tracking, order history and CSV export.
- Admin dashboard: orders, services, packages, portfolio, site content, staff permissions and settings.
- Full trilingual interface: **English / العربية / Français** with automatic RTL.
- Cloud sync (Supabase) with offline-first storage and automatic retry.

## Run locally

Open `index.html` in any modern browser. That is all.
